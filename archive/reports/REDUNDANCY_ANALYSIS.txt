ACTIVE USAGE FLOW
================================================================================

Command Line Entry:
    python3 run_scenario.py scenarios/downtown_crush.yaml

Execution Flow:
    1. run_scenario.py loads config_loader.py
    2. run_scenario.py creates scenario using scenario_generators
    3. run_scenario.py imports simulator_core.py + assignment_algorithms.py
    4. run_scenario.py calls run_simulation() for each algorithm
    5. run_scenario.py invokes create_consolidated_gifs.py (subprocess)
    6. create_consolidated_gifs.py calls export_detailed_logs.py
    7. run_scenario.py invokes create_focused_gifs.py (subprocess)
    8. create_focused_gifs.py calls export_detailed_logs.py
